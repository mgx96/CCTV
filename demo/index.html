CCTV

Cross-Chain Transaction Validator — an embeddable SDK that checks what a wallet is about to send or sign, before the user approves it.

Catch cross-chain mis-sends: wrong token-chain pairings, wrong CEX deposit networks, and address formats that don't belong to the destination chain. Fully offline — no RPC, deterministic, free.

Defend against the Bybit class of attacks — where a compromised UI shows a benign action while the wallet signs something malicious. CCTV decodes the actual calldata and EIP-712 payloads so the user sees what they're really approving.

The wallet supplies its own RPC provider, so simulation costs CCTV nothing. Call the validator inside your signing flow and block on the verdict.
